# Supermarket Customer Analysis

## Project Overview
This project analyzes customer purchasing behavior in a supermarket using exploratory data analysis (EDA). The objective of this project is to understand customer spending patterns, purchasing channels, and the potential impact of promotions on customer purchases.

The results of this analysis are expected to help businesses better understand their customers and improve marketing strategies.

---

## Business Problem
Supermarkets need to understand customer behavior in order to optimize marketing strategies and increase customer engagement.

This project attempts to answer several questions:

- Which product categories are most frequently purchased?
- Which purchasing channel is most commonly used by customers?
- How do customers interact with the supermarket website?
- Do promotions affect customer spending?

---

## Dataset
The dataset used in this project is **Supermarket Customers Dataset** which contains information about:

- Customer demographics
- Product purchases
- Purchase channels (store, web, catalog)
- Marketing campaign responses
- Promotion purchases

## Project Workflow

### 1. Data Understanding
Initial exploration was conducted to understand the structure of the dataset, including data types, number of rows and columns, and summary statistics.

### 2. Data Cleaning
The dataset was prepared for analysis by:

- Handling missing values
- Checking for duplicates
- Ensuring data types were correct

### 3. Exploratory Data Analysis (EDA)
EDA was performed to identify patterns and trends in customer purchasing behavior, including:

- Spending distribution
- Product purchase patterns
- Channel usage

### 4. Statistical Testing
Statistical tests were conducted to support the analysis, such as:

- T-Test
- ANOVA
- Chi-Square Test

---

## Key Insights

Some insights from the analysis include:

- Wine and meat products are among the most purchased product categories.
- In-store purchases are still the most commonly used purchasing channel.
- Customer interaction with the website is relatively low compared to in-store purchases.
- Promotional campaigns appear to influence customer spending.

---

## Recommendations

Based on the analysis results, several recommendations can be considered:

- Maintain strong in-store shopping experiences since many customers still prefer shopping directly in the store.
- Increase awareness of the supermarket website through marketing campaigns.
- Use the website as a platform to inform customers about upcoming promotions.
